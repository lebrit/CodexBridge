- Версия исходников: **0.11.1**, ветка `develop`. До этой задачи опубликован `v0.11.0-build.34.1`.
- Выполнен целевой аудит надёжности; исправлены пути восстановления и отката через junction/reparse points, небезопасные имена проектов и идентификаторы журналов, конкурентная запись JSON.

## Следующие шаги и ограничения

1. Приоритет: согласованность состояния GUI/агента и сохранение корней отключённых дисков; затем прогресс установки каждого приложения и повтор неудачных пунктов.
2. Усовершенствовать таймауты внешних команд/загрузок и перенос готового локального снимка в облако. Подробный план: [RELIABILITY_REVIEW.md](docs/RELIABILITY_REVIEW.md).
3. Проверка путей не является изоляцией от намеренной параллельной подмены каталогов другим процессом. JSON атомарен, но конкурирующие изменения полей пока не объединяются автоматически.
4. Интерактивная Windows 11, реальное облако, заполненный диск и физический перенос ещё требуют отдельной приёмки. Windows Server CI этого не заменяет.
5. Доверенной подписи пока нет; сертификат остаётся отдельным внешним условием.
