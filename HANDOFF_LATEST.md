# CodexBridge — передача контекста

## Текущее состояние

- Версия исходников: 0.10.0, ветка `develop`.
- Локальный релизный конвейер завершён: 42/42 теста, обязательная restic-лаборатория, public-safety, 36/36 GUI-состояний, self-contained ZIP и Inno Setup.
- Локальные пакеты: `CodexBridge-0.10.0-setup.exe` (68 471 557 байт, SHA-256 `e8a4de1af84568eaa2e15c5143b722b4b96c1e10fec52f9ba23328a5d5cd78f7`) и ZIP (94 027 292 байта, SHA-256 `13862c547d41d2dbb50fc742edc8a38a1e9062c0ba4656d3fa381b21f75e7237`). Оба файла ожидаемо `NotSigned`.
- Проверка NuGet с транзитивными зависимостями не нашла известных уязвимых пакетов.

## Что добавлено в 0.10.0

- Cross-runner CI: Windows Server 2022 создаёт синтетический зашифрованный restic-репозиторий, Windows Server 2025 выполняет полный check, restore `--verify`, SHA-256 и повторный запуск.
- Аварийные тесты: заблокированный файл, недоступный каталог и оборванная последняя запись журнала; прежние отмена, перезапуск и SHA-256 rollback сохранены.
- Отдельный режим мастера для нового компьютера: новый ключ и пустой репозиторий в нём не создаются, после завершения сразу открывается восстановление.
- Безопасный диагностический ZIP без настроек, ключа, каталога проектов и баз Codex; пути, имена проектов, облачный адрес, токены, ключи, e-mail, IP и URL очищаются.
- Проверка GitHub-релизов не чаще раза в сутки. Скачивание setup, проверка опубликованного SHA-256 и запуск требуют подтверждений.
- WPF recycling virtualization, доступные имена ключевых элементов и 36 состояний GUI, включая оба режима мастера.
- Inno Setup, установленный только для текущего пользователя, теперь автоматически находится скриптом сборки.

## Принятые решения

- Официальный Windows App SDK toast был собран в эксперименте, но увеличил один self-contained EXE примерно до 283 МБ. Эта зависимость удалена; релиз не раздувается ради необязательного уведомления.
- Реальное заполнение диска в CI не имитируется. Проверены безопасные детерминированные ветки `IOException`; full-disk остаётся для Windows VM.
- Cross-runner fixture содержит только синтетические данные. Однодневный CI-артефакт хранит тестовый пароль рядом с тестовым репозиторием и не читает пользовательский профиль.

## Осталось проверить извне

1. GitHub Actions должен подтвердить новые jobs и выпустить версионированный prerelease; до его завершения локальные хеши не являются хешами CI-релиза.
2. Нужна интерактивная Windows 11 VM: клавиатура, экранный диктор, DPI, toast-вариант без тяжёлой runtime и реальный сценарий заполненного диска.
3. Позже — физический компьютер, настоящий облачный remote, повторная авторизация Codex/GitHub и полный перенос пользовательской среды.
4. Доверенной подписи нет до появления достаточных публичных сигналов для повторной заявки либо решения о платном сертификате.

## Локальные знания

- Graphify обновлён в `--code-only` режиме и синхронизирован через `gfy sync`; для семантической индексации изменённых Markdown нужен внешний LLM API key, которого в окружении нет.
- Codebase Memory переиндексирован: 891 узел, 2870 рёбер. Obsidian обновлён с резервной копией.
- Graphify-артефакты и локальные индексы в GitHub не отправляются.
