# CodexBridge — передача контекста

## Выполнено

- Версия исходников: 0.9.1, ветка `develop`.
- Настоящий WPF-прогон 30 состояний GUI: обе темы, обычный и минимальный размер, шесть страниц и мастер настройки. Проверены контраст локального хранилища и расположение кнопок мастера; сохраняются PNG и явный результат.
- Прогон не читает пользовательский профиль и ключ, не запускает поиск проектов или бэкап. Используются демонстрационные данные.
- Деинсталлятор снимает задание Планировщика только при единственном действии, указывающем на агент данной установки. Одноимённые чужие задания сохраняются.
- CI разделён на сборку, независимую приёмку Windows Server 2022/2025 и публикацию. Обновление проверяется с опубликованного `v0.9.0-build.26.1`, а не с условного номера старой версии.
- Добавлены повторная установка, контроль сохранности данных, сценарии своего и чужого задания после обновления. Отчёты сохраняются 14 дней, публикация блокируется при ошибке.

## Следующие независимые шаги

1. Разделить restic-лабораторию на два отдельных GitHub runner: создание синтетического снимка на A и восстановление на B, без реальных ключей и проектов.
2. Добавить проверки отказов восстановления: нехватка места, недоступный путь, блокировка файла, прерывание и повторный запуск. Сохранять существующий предварительный план и журнал отката.
3. Реализовать нативные уведомления Windows с устойчивой идентификацией установленного приложения; не подменять их временным tray-процессом.
4. Когда появится возможность — ручная Windows 11 приёмка, клавиатура/экранный диктор, DPI и полный перенос на другую машину.

## Границы

- Windows Server runners не равны чистой Windows 11: на них есть предустановленные инструменты.
- Полный перенос между двумя компьютерами, реальные облачные аккаунты и повторная авторизация Codex пока не проверены.
- Доверенной подписи нет; публичные пакеты остаются неподписанными.
- По Ponytail использованы штатные WPF, Task Scheduler и GitHub Actions; новые UI-зависимости не добавлялись.
- Индексы Graphify/Codebase Memory локальны и не публикуются. В ненаправленном Graphify две пары взаимных ссылок документов представлены общими рёбрами; исходные ссылки сохранены в локальном семантическом кэше.
