# CodexBridge

CodexBridge — Windows-приложение с русским GUI для резервного копирования и безопасного восстановления проектов и настроек среды разработки.

Программа предназначена для обычных пользователей Codex, Git и других инструментов. VS Code поддерживается как необязательное дополнение: его карточка показывается, только если редактор найден на компьютере. CodexBridge не привязан к компьютеру автора и работает только с папками и хранилищами, которые выбрал сам пользователь.

## Что уже работает

- быстрый поиск Git- и не-Git-проектов только в выбранных корнях, без полного сканирования дисков;
- мастер первого запуска, правая навигация и светлая/тёмная тема;
- отдельное включение и исключение проектов;
- локальные зашифрованные restic-снимки с автоматическим созданием хранилища при первом backup;
- необязательная вторая копия в любом rclone-совместимом облаке;
- безопасное хранение рабочего ключа через Windows DPAPI;
- фоновый агент и ежечасное задание Планировщика Windows;
- проверка restic-репозитория и просмотр снимков;
- обычная и глубокая проверка части данных репозитория;
- необязательная политика хранения старых снимков;
- восстановление проектов в один новый корень;
- политика конфликтов без молчаливой перезаписи;
- перенос безопасной конфигурации Codex;
- необязательный перенос настроек, snippets и расширений VS Code;
- встроенный запуск мастера rclone и поиск уже настроенных remotes;
- постоянный `CodexBridge-errors.log` рядом с программой при возникновении ошибок;
- автоматические Windows-сборки и версионированные GitHub prerelease.

## Быстрый старт

1. Скачайте ZIP из раздела **Releases** и распакуйте его в постоянную папку.
2. Запустите `CodexBridge.App.exe`.
3. Пройдите мастер: выберите единую папку проектов, локальное хранилище и сохраните созданный ключ восстановления.
4. При необходимости нажмите «Установить restic и rclone».
5. Нажмите «Найти проекты сейчас» и проверьте список защищаемых проектов. Поиск обходит только выбранные корни; перед ручным и фоновым backup список обновляется автоматически.
6. Создайте первый backup: пустое локальное хранилище restic будет подготовлено автоматически. Затем проверьте его и включите ежечасное задание.
7. Для облака откройте мастер rclone из настроек, создайте remote и нажмите «Найти настроенные remotes». Адрес хранилища приложение подставит само.

Ключ восстановления нельзя восстановить из репозитория. Без него зашифрованные снимки недоступны.

## Приватность

CodexBridge не отправляет телеметрию и не содержит серверной части. Пути вроде `%USERPROFILE%\Documents` вычисляются на компьютере пользователя и не встроены в публичную сборку. Настройки и каталог проектов хранятся в локальном профиле Windows. При ошибке файл `CodexBridge-errors.log` создаётся рядом с EXE; если папка программы защищена от записи, используется `%LOCALAPPDATA%\CodexBridge`. В GitHub публикуются только универсальные исходники и собранная программа.

По умолчанию из снимков исключаются `.env`, приватные ключи, файлы аутентификации, активная база Codex и пересоздаваемые каталоги зависимостей. Вход в Codex, GitHub и облачные сервисы после переезда выполняется заново.

Перед каждой публичной сборкой запускается проверка на локальные пути, токены, приватные ключи и машинные отчёты.

Подробные обязательства проекта описаны в [Code signing policy](CODE_SIGNING_POLICY.md), включая политику приватности и роли сопровождения.

## Версии и сборки

- локальная версия хранится в `Directory.Build.props`;
- `scripts/Bump-Version.ps1 -Part patch` увеличивает версию для осмысленного релиза;
- каждый push в `main` или `develop` получает уникальную CI-версию;
- GitHub Actions запускает тесты, создаёт self-contained x64 ZIP, SHA-256 и prerelease.
- перед упаковкой готовый GUI запускается на чистом Windows runner и проверяется на раннее падение.

## Ограничения первой версии

- Windows 11 x64;
- подключение к облачному провайдеру выполняется в официальном интерактивном мастере rclone;
- конфигурационные файлы при конфликте сохраняются рядом как конфликт, автоматического TOML merge пока нет;
- приложение не копирует пароли, OAuth-сессии и внутреннюю SQLite-базу Codex;
- полное испытание переноса желательно провести на втором компьютере или чистой Windows VM.

Заявка CodexBridge в программу SignPath Foundation отправлена 8 августа 2026 года и ожидает рассмотрения. Текущие файлы остаются неподписанными, пока в примечаниях конкретного релиза не указано обратное. После одобрения подписанные релизы будут содержать уведомление: **Free code signing provided by SignPath.io, certificate by SignPath Foundation.** Самоподписанный сертификат в публичном релизе не используется.

## Сборка из исходников

```powershell
winget install --id Microsoft.DotNet.SDK.10 --exact
powershell -ExecutionPolicy Bypass -File .\scripts\Build-Release.ps1
```

Результат появится в `artifacts`.
